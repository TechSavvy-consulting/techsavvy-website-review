# Review notes · October 24, 2026

## Purpose and boundaries

This is the approved GitHub design example. Kyle subsequently authorized a public repository and online GitHub preview on October 24, 2026. The preview uses GitHub Pages at https://techsavvy-consulting.github.io/techsavvy-website-review/. The eventual production host remains undecided. No Netlify account, paid subscription, domain connection or production DNS change is included.

The public GitHub repository and local source are the working copy. The existing Wix site and the separate unpublished Wix landing-page draft remain independent.

## Design direction

- Preserve TechSavvy's blue-and-white identity and authentic wordmark.
- Separate readable text from the Kyle/server-room visual.
- Use consistent typography, spacing, cards, buttons and navigation.
- Lead with Tulsa business support for 10–100 computer/device users.
- Use the approved “Keep your tech working for you” direction.
- Keep a clear consultation/contact path and clickable phone numbers.
- Use a static existing testimonial excerpt rather than an autoplay carousel.
- Use the same “Blog” wording across navigation and homepage.

## Content changes for review

Marketing copy is a new review proposal. It preserves the main services, business details, source URLs and existing public assets, but it has not been approved as final production copy.

The three blog posts retain their original slugs, titles, authors and publication timestamps. Repeated source artifacts were removed. Unsupported statistics, case-study outcomes and blanket service/security guarantees were omitted or qualified. The Windows 11 article is labeled as an archive and notes the standard Windows 10 support end date. No new publication date is implied.

The existing privacy and accessibility text is retained with a prominent reference notice. Its Wix-specific statements describe the current production site. It must be adapted to the selected host and actual features before production. No claim of complete accessibility conformance is made for this example.

## Features deliberately incomplete

- Both form designs are inactive. Nothing typed is sent or saved. A production backend, spam handling, recipient routing, retention and notification delivery need implementation and end-to-end testing after host selection.
- The thank-you page is only a design preview and does not assert a submission succeeded.
- Wix comments, memberships, comment notifications and submission history were not exported or migrated. Blog comments are identified as not yet migrated.
- Optional visitor analytics, advertising pixels and consent popups are absent. Keep the approved essential-only approach unless Kyle changes it.
- The locally copied video has visible controls and no autoplay. Caption/transcript availability and content freshness still require a media review before production.
- Media ownership/license scope and any named-customer permissions must be confirmed for final production publication. The review reuses the existing public-site assets/testimonial; no new endorsement or blanket reuse permission is inferred.
- Search Console click/ranking/backlink baselines and a complete historical redirect inventory have not been measured in this design-build task.
